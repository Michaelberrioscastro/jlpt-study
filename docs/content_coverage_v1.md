## Content policy inside the project

A lesson asset can contain:

1. Source-derived structure and learning objectives.
2. Short source examples where appropriate.
3. Original interactive questions written for the app.
4. A `content_note` documenting provenance and coverage.

The app must not label generated scaffolding as if it were a transcription of the source book.
